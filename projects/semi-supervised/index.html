Semi-Supervised Learning for Semantic Segmentation with Synthetic Images

Personal continuation of the Masters Thesis

What happens when you have a model that can generate unlimited synthetic urban images, but almost no labeled real-world data? This project explores exactly that — using unlabeled synthetic images as a lever to improve semantic segmentation models through semi-supervised learning techniques.

Code not publicly available. This work is a personal continuation of the Masters Thesis and is part of an ongoing research project. The source code cannot be shared at this time.

Where do the images come from?

The synthetic images used in this project are generated by the fine-tuned diffusion models developed during the Masters Thesis. Those models were trained to produce realistic urban driving scenes guided by text captions. Rather than letting those generated images sit idle, this project puts them to work as unlabeled data in a semi-supervised segmentation pipeline.

The labeled real-world set is larger than the synthetic unlabeled pool — making this an exercise in extracting maximum signal from limited synthetic data, not just scale.

Techniques Explored

01

Pseudo-Labeling with Transformer Models

The synthetic unlabeled images are annotated automatically using large transformer-based segmentation models (such as SegFormer or Mask2Former). These architectures currently represent the state of the art for semantic segmentation, making them the most reliable source of pseudo-labels. Only high-confidence predictions are retained and used to supervise the training of the smaller target model, reducing the risk of propagating noisy labels.

02

Mean Teacher (Tarvainen & Valpola, 2017)

Two model instances share the same architecture: a student that trains normally via backpropagation, and a teacher whose weights are not updated by gradients but instead track an Exponential Moving Average (EMA) of the student's weights across training epochs:

wteacher = 0.99 · wteacher + 0.01 · wstudent

Because the teacher averages many past checkpoints, its predictions are more stable and less noisy than the student's at any given point. The teacher's outputs on unlabeled synthetic images serve as soft targets that guide the student, effectively leveraging temporal ensemble across training. This technique consistently achieves the best results among all approaches explored.

03

Knowledge Distillation via Self-Training

A large transformer-based segmentation model is first fine-tuned on the labeled real-world dataset. It is then used as a teacher to annotate the unlabeled synthetic images — but only its high-confidence predictions are kept as pseudo-labels. These filtered annotations are then used to train a significantly smaller DeepLabV3 model. This approach transfers knowledge from a stronger, heavier architecture into a compact model suitable for deployment, while using synthetic data as the distillation medium.

Results

All three semi-supervised approaches consistently outperform the supervised baseline trained exclusively on the labeled dataset, using the same hyperparameter configuration. Improvements range from +5 to +10% in segmentation performance metrics.

Mean Teacher achieves the most consistent gains across runs, making it the recommended approach for this setting. Its EMA-based teacher provides more reliable pseudo-supervision than either fixed pseudo-labels or single-checkpoint distillation.

This is an ongoing personal project. Further experiments and results will be shared here as the work progresses.
